# Code of conduct

This project follows the spirit of the Contributor Covenant: be kind, be
technical, assume good faith, and keep discussion about the work. Harassment,
personal attacks, and bad-faith conduct are not welcome in issues, PRs, or
reviews.

Enforcement: report concerns through the repository owner's GitHub profile or
the private security advisory flow. The owner (drawmeanelephant) is the sole
maintainer and final arbiter; repeated or severe violations result in being
blocked from the repository.

This is a small experimental project; the short version is: don't be a jerk.
